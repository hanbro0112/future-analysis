# 多空比分析策略

基於成交量和成交價的即時多空比判斷系統，整合於 Price Analyzer 服務中。

## 功能特色

### 1. 多時間區間分析
- **1分鐘視窗**：即時捕捉短線交易訊號
- **5分鐘視窗**：觀察中期趨勢動能  
- **30分鐘視窗**：判斷長線走勢方向

### 2. 價量關係分析
- 內外盤統計（主動買進 vs 主動賣出）
- 買賣量比例計算
- 價格變動趨勢追蹤
- 淨成交量監控（外盤 - 內盤）

### 3. 成交量爆量指標
- 與當日平均成交量比較
- 爆量比率計算（當前/平均）
- 爆量等級判定：
  - **極度爆量**：≥ 3.0x
  - **嚴重爆量**：≥ 2.0x
  - **爆量**：≥ 1.5x
  - **放量**：≥ 1.2x
  - **正常**：< 1.2x

### 4. 期現價差分析
- 期貨價格 vs 現貨指數
- 正價差 / 逆價差判定
- 價差百分比計算
- 趨勢信號：
  - **強勢正價差**（> 0.5%）：偏多
  - **正價差**（> 0.2%）：偏多
  - **中性**（-0.1% ~ 0.1%）
  - **逆價差**（< -0.2%）：偏空
  - **強勢逆價差**（< -0.5%）：偏空

### 5. 市場情緒指標 🆕
- **委買委賣比**：即時買賣掛單力道比較
  - 委買強勢：> 1.3
  - 委買優勢：> 1.1
  - 均衡：0.9 ~ 1.1
  - 委賣優勢：< 0.9
  - 委賣強勢：< 0.7
- **連續內外盤方向**：追蹤連續幾筆的買賣趨勢
  - 正數：連續外盤（主動買進）
  - 負數：連續內盤（主動賣出）
- **動能分數**（0-100）：結合價格變動和成交量的綜合動能
- **波動程度**：5個等級（極低、低、正常、高、極高）
- **綜合情緒分數**（0-100）：加權計算的市場情緒
  - 極度貪婪：≥ 75
  - 貪婪：≥ 60
  - 偏貪婪：≥ 55
  - 一般：45 ~ 55
  - 偏恐慌：≥ 40
  - 恐慌：≥ 25
  - 極度恐慌：< 25

### 6. 綜合多空比判斷
結合以上所有指標，給出加權計算的多空比例：
- **強多**：多方 ≥ 70%
- **偏多**：多方 ≥ 58%
- **中性**：多方 42% ~ 58%
- **偏空**：多方 ≤ 42%
- **強空**：多方 ≤ 30%

## 演算法說明

### 多空比加權評分機制
1. **短期價量**（權重 25%）：1分鐘視窗的買賣力道和價格動能
2. **中期趨勢**（權重 30%）：5分鐘視窗的趨勢方向
3. **長期趨勢**（權重 20%）：30分鐘視窗的整體走勢
4. **爆量指標**（權重 15%）：成交量異常時的方向判斷
5. **期現價差**（權重 10%）：市場情緒的領先指標

### 情緒指標計算機制
情緒分數由以下因素加權計算：
1. **委買委賣比**（權重 30%）：即時掛單力道
   - > 1.3 → 70分（委買強勢）
   - > 1.1 → 60分（委買優勢）
   - 0.9~1.1 → 50分（均衡）
   - < 0.9 → 40分（委賣優勢）
   - < 0.7 → 30分（委賣強勢）

2. **連續內外盤方向**（權重 25%）：追蹤主動買賣趨勢
   - 連續 ≥5 筆外盤 → 75分
   - 連續 ≥3 筆外盤 → 65分
   - 連續 ≥1 筆外盤 → 55分
   - 連續 ≤-5 筆內盤 → 25分
   - 連續 ≤-3 筆內盤 → 35分
   - 連續 ≤-1 筆內盤 → 45分

3. **動能分數**（權重 35%）：價格變動與成交量配合度
   - 結合價格變動（60%）和買賣比（40%）
   - 範圍 0-100，50 為中性

4. **波動率調整**（權重 10%）：高波動降低信心
   - 極高/高波動：拉向中性
   - 正常波動：追隨動能

### 信心水準
基於資料充足度計算，5分鐘內累積 50 筆 Tick 達到 100% 信心水準。

```python

```

## 資料儲存

所有分析結果儲存在 Firestore 的 `price_analysis` Collection 中，包含：
- 原始 Tick 資料
- 多空比分析結果
- 各時間視窗統計
- 爆量指標
- 期現價差分析

可透過 Firebase Console 或 API 查詢歷史分析資料。
